# Diplom_3

## Задание 3: UI-автотесты для Stellar Burgers

Проект предназначен для автоматизации UI-тестов веб-приложения Stellar Burgers.

В рамках задания будут проверены:

* переход по клику на раздел «Конструктор»;
* переход по клику на раздел «Лента заказов»;
* открытие всплывающего окна с деталями ингредиента;
* закрытие всплывающего окна;
* увеличение счётчика ингредиента при добавлении в заказ;
* увеличение счётчика «Выполнено за всё время» после создания заказа;
* увеличение счётчика «Выполнено за сегодня» после создания заказа;
* появление номера заказа в разделе «В работе».

Тесты будут реализованы с использованием паттерна Page Object.

Проверка будет выполняться в браузерах Google Chrome и Mozilla Firefox.

Для отчётности будет подключён Allure.
